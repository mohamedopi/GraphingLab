# Graphing Lab — تطبيق Android للرسم الرياضي

تطبيق Kotlin + WebView يعمل بدون إنترنت:
- رسم 2D للدوال `y=f(x)` مع محاور وتدريج وتحريك/تكبير باللمس.
- رسم 3D للأسطح: ديكارتي `z=f(x,y)`، أسطواني `z=f(r,theta)`، كروي `r=f(theta,phi)`.
- تدرّج ألوان أزرق ← سماوي ← أخضر ← أصفر، وتدوير وتكبير باللمس.
- محلل معادلات آمن: `-x^2` و`2x` و`sin(x)cos(x)` و`pi` و`ln` و`log10` و`atan2` وغيرها.

## الحصول على APK
1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع **محتويات** المجلد (وليس مجلدًا يحتويها) إلى جذر المستودع، بحيث يظهر `settings.gradle` و`app` و`.github` في الصفحة الرئيسية.
   - من الكمبيوتر: اسحب كل الملفات والمجلدات إلى صفحة Add file ← Upload files (تأكد من ظهور `.github`).
   - أو بالأوامر: `git init && git add . && git commit -m init && git branch -M main && git remote add origin <رابط المستودع> && git push -u origin main`
3. افتح تبويب **Actions**. سيبدأ بناء **Build Graphing Lab APK** تلقائيًا (أو شغّله بـ Run workflow). يستغرق 3 إلى 6 دقائق في أول مرة.
4. بعد النجاح افتح **Releases** في الصفحة الرئيسية للمستودع ونزّل `GraphingLab.apk` مباشرة من الهاتف.
5. ثبّته (اسمح بالتثبيت من المتصفح عند السؤال).

كل رفع جديد إلى `main` يبني نسخة جديدة ويستبدل الملف في Releases. التحديث يثبّت فوق النسخة القديمة لأن التوقيع ثابت ورقم النسخة يزيد تلقائيًا.

## ملاحظات
- الملف `app/debug.keystore` مفتاح توقيع تجريبي معروف الكلمة السرية؛ مناسب للاستخدام الشخصي. لا تستخدمه للنشر على Google Play.
- الزوايا بالراديان. في الكروي: `theta` من 0 إلى 2π و`phi` من 0 إلى π.
- المعادلات الضمنية مثل `F(r,theta,phi)=0` غير مدعومة.
- لتعديل الواجهة غيّر `app/src/main/assets/index.html` فقط.
